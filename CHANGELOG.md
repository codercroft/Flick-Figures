## 2026-11-24: Fat Man grab delay, Wrap Gift badge
- Fat Man's grab turn waited about 6 s for nothing. Cause: the settle check waits until every figure `is_resting()`; a held figure is frozen (its `_integrate_forces` never runs, so its slow-frame count cannot rise) and the hand's per-frame `teleport_to` resets that count to 0, so it never rested and the 6 s forced settle always ended the turn. Fix: `Figure.is_resting()` returns true while `held`. Timing (`tools/fat_timing_test.gd`, enemy turn from its start to the player's turn): grab 7.5 s -> 1.8 s (0.6 think + 0.45 reach + 0.45 return + 0.3 settle); throw turn 1.4 s before and after (the thrown figure is a normal moving figure; nothing was held any more). The hand is not a figure, so it was never part of the settle check; the AI does not search shots on a grab turn.
- Ghost Wrap Gift: a small ghost badge above every figure that holds a wrap charge (the `ghost_wrap` meta), gone when the wrap is used (test in `field_changes_test.gd`).
